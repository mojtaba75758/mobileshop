۵ قدم ساده — از ساخت حساب GitHub تا ثبت در Google Search Console

💡 این راهنما assume Monate که سایت را رایگان روی GitHub Pages منتشر می‌کنی — نیازی به خرید هاست نیست!
۱

ساخت حساب در GitHub

به سایت github.com برو و روی دکمه Sign up کلیک کن. با ایمیل خودت یک حساب رایگان بساز.

  • ایمیل و رمز عبور را وارد کن
  • ایمیل خود را تأیید کن
۲

ساخت مخزن (Repository) جدید

بعد از ورود، روی New repository کلیک کن و نام مخزن را مثلاً mobileshop بگذار. گزینه Public را انتخاب کن و روی Create repository بزن.

۳

آپلود فایل‌های سایت

در صفحه مخزن روی Add file → Upload files کلیک کن و این فایل‌ها را از پوشه shop/ آپلود کن:

  • index.html — صفحه اصلی
  • styles.css و app.js
  • sitemap.xml و robots.txt
  • پوشه guide/ (عکس‌های راهنما)

سپس روی Commit changes کلیک کن.

۴

فعال‌سازی GitHub Pages

به Settings → Pages مخزن برو. در قسمت Source گزینه Deploy from a branch را انتخاب کن، شاخه main و پوشه root را بگذار و Save را بزن.

چند دقیقه بعد سایتت روی آدرس زیر آنلاین می‌شود:

https://نام-کاربری-تو.github.io/mobileshop/

۵

ثبت سایت در Google Search Console

به search.google.com/search-console برو و با حساب谷歌‌ات وارد شو:

  • روی Add property بزن و آدرس سایتت را وارد کن
  • مالکیت دامنه را با فایل HTML یا رکورد DNS تأیید کن
  • از منوی Sitemaps، آدرس sitemap.xml را ارسال کن

بعد از چند روز، گوگل شروع به ایندکس کردن صفحات سایتت می‌کند! 🎉

⚠️ یادت نره: بعد از آنلاین شدن سایت، آدرس https://mobileshop.af را در فایل‌های sitemap.xml و robots.txt با آدرس واقعی خودت عوض کن!
